Backup & Restore

Export everything (schedule, findings, plant guide, grow log, house rules, attendance, staff) as a JSON file you can keep somewhere safe. Import restores from a previously exported file — it will overwrite whatever's currently in the database, so use it deliberately.

Clear a collection

Moves every record in one collection to Trash (below) — meant for right before importing a corrected file, so the old and new records don't end up mixed together. Recoverable from Trash afterward if needed.

Trash

Anything deleted anywhere in the app — a single entry, or a whole collection cleared above — lands here first instead of being removed right away. Kept for 365 days (purged the next time an admin has this page open after that, since there's no server running in the background to do it on a schedule), or delete it forever yourself any time.
